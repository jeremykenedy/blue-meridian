# Blue Meridian 1.0.1

Earth stays visibly sunlit as its surface rotates. Detailed NASA surface, cloud, and night-light composites replace the earlier surface and procedural effect layers, with a thin atmosphere and quieter star motion.

## Upgrade guide

Install the signed `blue-meridian.apk` over version 1.0.0 using the existing signing key. Android 6.0 / API 23 and OpenGL ES 2.0 remain required. Package identity, all seven preference keys, defaults, and settings-provider paths are unchanged. No data migration or reset is needed.

```bash
python3 install.py --serial TV_IP:5555
```

The installer downloads the latest stable APK and verifies its checksum. Verify a manual download with `shasum -a 256 -c blue-meridian.apk.sha256`, then install it using ADB. The installer preserves the current selected screensaver. Open Blue Meridian settings, preview the animation, and confirm the chosen options.

## Breaking changes

None. This is a compatible rendering and correctness update. Existing choices remain saved.

## Major changes

- Keep sunlight in view space while the surface texture rotates, preventing the whole visible hemisphere from becoming black during each revolution.
- Correct the latitude projection so north stays above south.
- Use NASA Blue Marble surface and cloud composites and mapped Black Marble city lights, with independent cloud drift and cloud shadows.
- Reduce the oversized atmosphere glow and preserve a thin, sunlit limb.

## Minor changes and fixes

- Add mipmapped textures and downsampling to the device's supported texture limit.
- Move background stars slowly to avoid fixed bright points.
- Enforce actual 100 percent line and branch coverage ratios for the owned pure Java logic.
- Add a native lighting regression that reproduced the lost daylight on 1.0.0 and checks three phases of a real rotation.
- Refresh native captures, preview, media provenance, and animated desktop and mobile banners.

## Verification

Host tests, installer and pure Java coverage, formatting, documentation, privacy and style checks pass locally. Native API 31 emulator checks cover rotating daylight, all seven settings, persistence, invalid-value rejection and Home/Back resume. The signed APK preserves the published signing certificate and includes media attribution. Physical-device and final publication checks remain pending; see [device verification](https://github.com/jeremykenedy/blue-meridian/blob/v1.0.1/docs/VERIFICATION.md).

## Security and data integrity

The app retains no Internet permission, runtime network client, analytics, or reporting. NASA composites are bundled locally and are archival visualization inputs. Source attribution and hashes are documented in [the media guide](https://github.com/jeremykenedy/blue-meridian/blob/v1.0.1/docs/MEDIA.md) and NOTICE.

## Rollback

Android blocks installing a lower version code over this release. Record the seven settings before uninstalling. Install the signed 1.0.0 APK after uninstalling 1.0.1, then reapply the saved choices. No automatic backup or downgrade is provided.

## Known limitations

Physical Fire TV, physical Android TV, physical Google TV, native 4K composition, extended thermal behavior, and idle activation are not verified for this candidate. Volunteers with those devices can report model, OS/API, display mode, and selection, playback, remote-exit, and sleep/wake results. The cloud and night-light composites are historical data from different years, not live weather.

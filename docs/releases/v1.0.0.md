# Blue Meridian 1.0.0

First stable release of Blue Meridian, an animated Earth screensaver for Fire TV, Android TV and Google TV.

## Included

- OpenGL ES 2 rotating Earth with day/night shading, camera drift and a star field.
- Optional atmosphere, moving clouds and night-side city lights.
- Slow, natural and fast rotation; still, gentle and sweeping camera motion; sparse, natural and dense stars.
- Independent Random selections and master randomization on each start.
- Native settings screen and versioned settings provider for host applications.
- Guided installer, updater and uninstaller. Install/update downloads the latest release and checks SHA-256 before applying it.
- No ads, analytics, tracking, telemetry, crash reporting or runtime network access.

## Compatibility

The app targets Fire TV, Android TV and Google TV devices with Android 6.0 or newer and OpenGL ES 2.0. The current release was functionally verified on Android TV emulator API 31 at 1920x1080. No physical Fire TV, Google TV or 4K display behavior is claimed as tested.

## Upgrade

Install `blue-meridian.apk` over an existing Blue Meridian installation signed with the same key. The guided installer can download and verify the latest release:

```bash
python3 install.py --serial TV_IP:5555
```

For manual install, verify the downloaded checksum from the release directory:

```bash
shasum -a 256 -c blue-meridian.apk.sha256
```

Then install the APK with ADB and select Blue Meridian in the device's screensaver settings. This release introduces the package and commands; there is no earlier version migration.
